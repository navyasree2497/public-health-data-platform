# Public Health Analytics Data Platform

## Overview

This project demonstrates an end-to-end public health analytics data platform designed to integrate, standardize, validate, and analyze data received from multiple healthcare and public health organizations.

The project simulates a real-world environment where different organizations collect similar program information using different data structures, variable names, activity definitions, and reporting formats.

The platform transforms these heterogeneous datasets into a standardized reporting model that can support analytics, data quality monitoring, and business intelligence reporting.

## Business Problem

Public health organizations often receive program data from multiple providers and community organizations. Although these organizations may report similar activities and outcomes, their source datasets frequently use different:

- Column names
- Activity definitions
- Reporting month formats
- Data structures
- Geographic information
- Target audience classifications

These inconsistencies make centralized reporting, data validation, and cross-program analysis difficult.

## Project Goal

The goal of this project is to build a scalable data platform that:

- Integrates data from multiple synthetic public health organizations
- Standardizes activity and reporting information
- Uses metadata-driven mappings instead of hard-coded transformations
- Performs automated data quality validation
- Creates analytics-ready reporting datasets
- Supports downstream Power BI reporting

## Data Privacy

All datasets used in this repository are completely synthetic and were created specifically for demonstration purposes.

No confidential, protected health information (PHI), personally identifiable information (PII), employer data, or production data is included.
